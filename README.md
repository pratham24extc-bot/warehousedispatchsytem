# 📦 Warehouse Dispatch System – Java

A Java Swing-based Warehouse Dispatch System developed as a micro-project for managing warehouse dispatch orders efficiently.

## 📌 Project Overview

The **Warehouse Dispatch System** is a desktop application developed using **Java and Java Swing**. It helps warehouse operators manage dispatch orders through a simple graphical user interface.

The system allows users to add, search, update, and delete dispatch orders while maintaining important information such as product details, quantity, destination, and dispatch status.

This project demonstrates important Java programming concepts including **Object-Oriented Programming, Java Swing, event handling, ArrayList, input validation, and CRUD operations**.

---

## ✨ Features

- ➕ Add new dispatch orders
- 🆔 Automatic Order ID generation
- 📦 Product ID management
- 📝 Product Name management
- 🔢 Quantity validation
- 📍 Destination management
- 🔄 Dispatch status management
- 🔎 Search dispatch orders
- ✏️ Update order status
- 🗑️ Delete dispatch orders
- 📊 View basic dispatch statistics
- ⚠️ Input validation and error handling
- 🖥️ User-friendly graphical interface

### Dispatch Status

The system supports the following statuses:

- Pending
- Packed
- Dispatched
- Delivered
